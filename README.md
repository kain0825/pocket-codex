# Pocket Codex

项目主页：[github.com/kain0825/pocket-codex](https://github.com/kain0825/pocket-codex)

**把 ESP32-P4 触屏开发板变成 Codex 随身终端。**

通过局域网查看电脑上的聊天与任务状态，用板载麦克风下达指令，在设备上停止任务、补充要求、回答问题；附带电脑监控、设备工具和实体按键待机。

当前为 **0.1.0 源码预览版**，从个人使用中的 Pocket 系统提取。公开版的构建与测试状态见 [验证记录](docs/verification.md)。欢迎复现、报告问题和参与维护。

> 本项目由社区独立开发，与 OpenAI、乐鑫或 GUITION 没有官方隶属或认证关系。Codex 的推理和语音转写在电脑端完成，小板承担显示、录音和操作入口。电脑需要保持运行，设备需要能访问电脑的局域网地址。

## 能做什么

| 模块 | 能力 |
|---|---|
| Codex | 最近活跃／按项目浏览、聊天切换、回复阅读、三标签分页、任务状态与额度 |
| 语音输入 | 设备录音、电脑本地转写、核对或快速发送、取消录音、保留旧草稿 |
| 任务交互 | 停止正在执行的任务、发送中途引导、继续任务、打开并回答待回答问题 |
| 草稿 | 查看、编辑、九宫格拼音、上一轮草稿与复制粘贴补救 |
| 电脑监控 | CPU、内存、NVIDIA GPU／显存／温度／功耗；不支持的数据留空 |
| 电脑控制 | 显示器单屏／扩展切换、休眠和关机；危险操作有设备端确认 |
| 设备 | 读卡器、离线计算器、电子木鱼、答案之书、独立小智入口 |
| 待机 | BOOT 实体键息屏／唤醒、触摸不唤醒、暂停界面动画与常规同步、软件时钟 |

**公开版不包含独立口述记录、日记整理、个人资料库、Obsidian 导入或这些功能的同步工作流。** Codex 对话中的语音输入保留。仓库不包含作者的录音、转写、聊天记录、存储卡备份或账号配置。

## 硬件与电脑

- 已有原系统使用基础：**GUITION JC4880P443C-I-W / ESP32-P4＋ESP32-C6**。
- 480×800 触屏、16MB Flash、32MB PSRAM、板载 ES8311 音频、TF 卡。
- Codex 语音输入需要 TF 卡；播放需要另接适配的喇叭。
- 当前桌面桥面向 **Windows 10/11、Python 3.11、Node.js**。NVIDIA 监控使用 `nvidia-smi`，没有 NVIDIA 显卡时相应字段显示未知。
- 固件开发基线为 **ESP-IDF 5.5.4**；当前不承诺其他 P4 板型或 macOS 桌面控制兼容。

具体引脚和两个 Type-C 口的用途见 [硬件说明](docs/hardware.md)。仅有相同芯片不足以直接刷其他板子的固件。

## 开始使用

1. 在 Windows 电脑安装 Python 3.11、Node.js 和 ESP-IDF 5.5.4，并安装/打开 Codex 桌面应用。
2. 创建 Python 环境并安装依赖：

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r host/requirements.txt
   ```

3. 按 [电脑端安装](docs/host-setup.md)配置本机聊天和局域网地址，生成本地配对配置，编译 Windows 控制助手。
4. 按 [固件构建与恢复](docs/firmware-build.md)构建自己的固件，再核对板型和原有分区后安装。
5. 启动电脑同步桥与监控服务，让开发板连接同一可互通的局域网。

**首版不提供可通刷的预配对二进制。** 每次配对应使用自己的随机密钥和证书。`*.local.*`、证书私钥、运行日志、聊天/语音目录及构建目录默认由 Git 忽略。

## 当前边界

- Codex 桌面适配使用本机安装的桌面工具传输与 Windows UI Automation，依赖桌面版本和可用插件。这不是稳定的公开 Codex 服务端 API，也没有绕过登录或修改 Codex 数据库。
- 停止任务／回答问题等原生按钮适配可能受桌面升级、语言和窗口布局影响。未知结果不会当作成功，也不会自动重放写操作。
- 跨聊天待回答提醒、共享网络调度及长时间负载稳定性仍需完善。
- **Wi-Fi 固件更新存在未解决的看门狗重启，公开版不提供无线刷机入口。** 日常聊天 Wi-Fi 同步与固件 OTA 是两条不同链路。
- 待机属于息屏和任务暂停策略，未宣称深睡指标或实测续航。电池百分比为电压估算，未经过容量校准。
- 单段 Codex 语音上限为 10 分钟；最大边界与复杂并发场景尚需更多实机验证。

更多记录见 [已知问题](docs/known-issues.md)。

## 项目结构

```text
firmware/                P4 固件、原生 UI、音频和应用模块
common_components/       保留许可的板卡与硬件组件
host/codex_sync/         Windows Codex 同步、语音、问题和任务控制桥
host/monitor/            本机电脑监控与控制服务
scripts/                 配置生成、构建辅助与发布检查
assets/                  有明确授权的字体与木鱼短音效
docs/                    安装、硬件、边界、验证和视频演示提纲
```

## 参与维护

报告问题时请附：固件版本、板卡型号、电脑系统/Codex 版本、复现步骤和**已删去私人信息的**日志。请勿上传配对密钥、完整聊天、原始录音、个人文档或整机 Flash 备份。

优先方向：稳定的连接恢复、并发调度、跨聊天提醒、录音和页面切换压力测试、其他电脑平台适配。参见 [贡献说明](CONTRIBUTING.md)及 [安全说明](SECURITY.md)。
