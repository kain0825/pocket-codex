# 已知问题与后续工作

公开版提取自已有日常原型，以下事项保持真实状态，不以发布仓库代替验收。

- Codex桌面工具和Windows原生控件的适配依赖具体版本；升级后可能需要修正。
- 多聊天正文、录音和网络请求在复杂负载下还需扩大压力测试；优先保障采集和输入保全。
- 跨聊天待回答提示不是可靠全局推送。选中聊天的问题读取与桌面可见状态相关，可能存在同步空窗。
- 历史上曾出现一次待机唤醒命令25秒超时，随后恢复，三次复测正常；根因未闭合。
- 无线固件更新曾触发P4看门狗重启；公开版不开放OTA命令入口，USB刷写仍需核对运行槽。
- 待机没有硬件深睡功耗/续航实测结论，电池百分比也未校准。
- 真实10分钟录音与50次切页/30次待机等扩大验收仍需后续专项执行。
- 原系统功能的用户验收记录不等于新公开提取版已经逐项在设备上复测。
- 目前只有Windows桌面桥，Mac和其他开发板需要各自适配。

请在Issue中说明步骤和版本，以便区分连接、桌面适配、采集、绘制和存储的问题。日志与截图请先删除个人内容。
