# 硬件说明

首个目标是 GUITION JC4880P443C-I-W，ESP32-P4 主控配 ESP32-C6 无线协处理、480×800 ST7701 显示和 GT911 触摸、16MB Flash、32MB PSRAM。板型配置位于 `firmware/main/boards/guition-jc4880p443/`。

| 音频信号 | P4 引脚 |
|---|---|
| ES8311 I²C SDA／SCL | GPIO7／GPIO8 |
| I²S MCLK／WS／BCLK | GPIO13／GPIO10／GPIO12 |
| I²S 输入／输出 | GPIO48／GPIO9 |
| 功放使能 | GPIO11 |
| BOOT 待机键 | GPIO35 |
| 屏幕背光 | GPIO23 |

两个设备端 Type-C 用途不同：调试/刷写口提供 USB Serial/JTAG，另一口提供原生 USB 读卡器功能。电脑只需一个接口。端口号和 USB 序列号应以自己的设备枚举为准，不使用作者的 COM 号或序列号。

请先确认屏幕/PCB和P4芯片修订，不把其他板子的合并镜像直接写入。本项目不自动刷写 C6，不要求通过重刷无线协处理器来安装 P4 应用。

TF 卡挂载失败不会自动格式化。读卡器模式必须由电脑安全弹出后，再在设备端退出，避免两个主机同时写卡。

电池电压读取沿用板级实现，百分比为估算。充电由板上硬件处理；本项目没有验证所有第三方电池的容量、保护板或充电匹配，也不以软件实现充电保护。
