# 项目介绍视频提纲

项目入口：https://github.com/kain0825/pocket-codex

目标：约60—90秒，让观众看到设备能做什么，再通过GitHub进入项目。先完成公开版实机验收再录制，演示使用独立测试聊天，不展示真实项目和私人消息。

| 时间 | 画面 | 讲述重点 |
|---|---|---|
| 0—8秒 | 手持小板，进入最近聊天 | “我给Codex做了一个能带在手上的小终端。” |
| 8—25秒 | 点开始说话，说一句测试指令，停止，电脑收到并回复 | “用开发板自己的麦克风说话，电脑转成文字，发送到选中的聊天。” |
| 25—40秒 | 打开第二条测试聊天，展示任务状态；测试中途补充或停止 | “不只是看状态，也可以切换聊天、补充要求和停止当前任务。” |
| 40—50秒 | 打开测试问题卡，点选答案，电脑收到 | “需要我做决定时，可以直接从小板回答。” |
| 50—65秒 | CPU/GPU监控；BOOT息屏后按键唤醒 | “附带电脑监控和设备工具，用完按键待机。” |
| 65—80秒 | 仓库首页、硬件型号、链接 | “项目叫Pocket Codex，第一版源码已经公开。需要Windows电脑和局域网，目前是持续完善的原型，欢迎一起测试。” |

建议标题：**我把Codex做成了一个随身小终端｜Pocket Codex开源**。

简介首行放实际GitHub仓库链接；其后写清目标板型、电脑依赖和源码预览状态。避免把电脑端推理说成板载本地AI，也不承诺所有板型即刷、实时语音通话或已解决全部稳定性问题。

本文件是拍摄提纲，尚未生成或发布视频。
